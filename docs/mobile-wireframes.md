# Mobile Wireframes (Text)

## Pre‑Cleaning
```
[Header: MACY – Production]
[Step 1: General Information]
  - Employee Name (input)
  - Date/Time (read-only)
  - Bags Used (numeric)
[Step 2: Equipment & Safety Questions]

  - Q2 ...
[Primary CTA: Submit Pre‑Cleaning] (sticky bottom)
```

## Post‑Cleaning
```
[Header: MACY – Area]
[Step 1: Employee + Date]
[Step 2: Bags Retrieved]
[Step 3: Post‑Clean Checklist]
  - Each question (select)
  - Conditional Comment + Photo
[Step 4: Handover Tasks]
  - Handover Yes/No
  - Task inputs (if Yes)
[Damage Review Button]
[Primary CTA: Submit Post‑Cleaning] (sticky bottom)
```

## Damage Report

[Header: Damage Report]

```

```
[Header: Handover Tasks]
